## Використаний промпт

Use case: background-extraction. Edit target: attached original 1280x1280 character. Remove only the solid black background, output real transparent alpha background. Preserve exact character appearance, face, hair, smile, open eyes, black hoodie and raised waving right-side hand. Preserve original square framing, all pixel positions and proportions as closely as possible, character from x130 to1140 y215 to1060. Do not crop or reposition. Do not remove black hoodie. No text or added objects. Asset for a web animation rig.
