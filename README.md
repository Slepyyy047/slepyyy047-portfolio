# Slepyyy047 — портфоліо

Мінімальне портфоліо у чорно-червоній палітрі. На першому екрані — монохромний портрет, великий PORTFOLIO та одна кнопка «Мої роботи» з частинками. Далі — безперервна стрічка сайтів, короткий опис автора й контакти.

## Локальний запуск і перевірки

```sh
npm start
npm run check
npm test
npm run build
```

Локальна адреса: http://localhost:4173. Сторінка робіт: /works. Vercel публікує тільки dist/. Збірка додає версію до модулів, стилів та HTML-посилань на зображення.

index.html і works/index.html мають бути однаковими. Дані, шість проєктів і категорії зібрані в content.js. Нові обкладинки також потрібно включати в assets у scripts/build.mjs.

## Рух

Стрічка рухається постійно: кнопки зупинки й паузи від наведення немає. Вона декоративна, а роботи відкриваються через «Мої роботи». Системне зменшення руху залишає статичну стрічку з горизонтальною прокруткою.

wave.js зберігає хвилю заголовка за один жест прокрутки. letters.js додає локальну взаємодію літер із курсором. motion.js відповідає за короткі появи елементів. Спойлери в галереї відкривають прев’ю першим натисканням, деталі — наступним; діалоги підтримують Escape, Tab та повернення фокусу.

Для ручного запуску браузерної регресії є scripts/browser-check.mjs: він використовує вже встановлений Playwright (PLAYWRIGHT_PATH), приймає TEST_URL. Наявність скрипта не є підтвердженням його запуску; звіти та скриншоти створюються в artifacts/.

## Зображення

Портрет і шість скриншотів надані користувачем. portrait-hero.webp — оптимізований прозорий портрет шириною 1100 px; монохром задається CSS. Походження матеріалів описане в assets/PROVENANCE.md. Колишні пейзаж, малий портрет, ілюстрація кварталу та wordmark.js збережені у вихідному коді, але не входять у збірку.
