# Slepyyy047 — особисте портфоліо

Українське портфоліо про створення сайтів. На головній — великий центрований вступ на тлі гірського озера: сцена залишається на місці під час прокручування, а рух указівника делікатно зміщує пейзаж. Заголовок реагує на прокручування хвилею по літерах. Одразу під вступом — помітний розділ «Про мене» з портретом, далі — темна сланцево-синя асиметрична галерея LAMPERA та BARBERLAB.

Сайт працює на звичайних HTML, CSS і JavaScript без сторонніх залежностей у браузері. Для локального сервера потрібен Node.js.

## Запуск

```sh
npm start
```

Відкрийте http://localhost:4173. Сторінка робіт доступна за адресою http://localhost:4173/works. Сервер слухає лише локальний інтерфейс.

Для статичного хостингу використовується `works/index.html` як копія головного HTML-файлу. Після змін у `index.html` оновіть копію командою PowerShell:

```powershell
Copy-Item index.html works/index.html
```

Продакшн-збірка: `npm run build`. Vercel публікує лише папку `dist/`; вихідні PNG, тести й локальний сервер не роздаються. Збірка додає версію до CSS, JS та ресурсів, щоб оновлення не залишалися в кеші.

## Рух і доступність

- `nature.js` керує делікатним паралаксом пейзажу. Паралакс від указівника вимкнений на сенсорних пристроях; масштабування фону під час прокручування залишається. З `prefers-reduced-motion` усі ці ефекти вимкнені.
- `wave.js` запускає повну хвилю після першого невеликого руху скролу (понад 6 px). Анімація триває 2,2 секунди та завершується сама без додаткового прокручування; повернення на початок відновлює заголовок. Додаткова висота першого екрану — лише 64 px.
- `motion.js` запускає короткі появи слів, текстів, портрета й прев’ю робіт при вході в кадр. Затримка між словами обмежена 160 ms незалежно від довжини тексту. Елементи доступні з клавіатури; reduced motion показує все відразу.
- `letters.js` додає локальне підняття й поворот літер заголовків біля курсора. Розрахунок виконується лише за рухом указівника; на touch та з reduced motion ефект вимкнений.
- `wordmark.js` створює локальний ефект на літерах PORTFOLIO біля курсора.
- У `app.js` реалізовані навігація між головною і `/works`, спойлери прев’ю (перше натискання відкриває фото, наступне або кнопка «Деталі» — діалог), керування клавіатурою й фокусом, контактні посилання та копіювання email, якщо його додано до конфігурації.
- Портрет у розділі «Про мене» обрамлений тонкими контурами; опис підкреслений вертикальною лінією та переліком напрямів роботи. Галерея має темний градієнт, великі назви й матові спойлери.

## Перевірки

```sh
npm run check
npm test
```

`npm test` запускає 24 модульні перевірки даних, посилань, обробки зображень, хвильового руху (зокрема тривалості й реверсу), паралаксу, руху літер і ефекту логотипа.

Для браузерної перевірки запустіть сервер і `scripts/browser-check.mjs` у другому терміналі. Скрипт використовує наявний Playwright: за потреби вкажіть шлях до модуля через `PLAYWRIGHT_PATH`; `TEST_URL` змінює базову адресу (за замовчуванням `http://localhost:4173`). Перевірки покривають головну й `/works`, переходи, спойлери прев’ю та діалоги, фокус і клавіатуру, ширини від 320 до 1440 px, хвилю заголовка, рух і reduced motion, контакти та стани з відсутніми зображеннями. Скрипт зберігає звіт і знімки в `artifacts/`. Цей опис перелічує покриття перевірок і сам по собі не підтверджує результат останнього браузерного запуску.
